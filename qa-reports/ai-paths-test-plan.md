# Test Plan — AI-assisted paths (fd_match, fd_profile)
Generated by /plan-eng-review on 2026-07-14
Branch: bugfix/mcp-playwright-async

Scope: harden the two surfaces that use `app/ai.py` now that an Anthropic key is
configured. The weekly cart-builder (`build_plan`) does not use AI and is out of
scope. Tests use a mocked Anthropic client — no real API calls.

## Affected modules
- `app/ai.py` — `rank_products`, `synthesize_profile`, `is_configured`, `_first_tool_input` (0% covered today)
- `app/match.py` — `resolve()` AI branch + new `calibrated_confidence()` helper
- `app/profile.py` — `infer_profile(use_ai=True)`

## Key behaviors to verify
- `is_configured` true from settings key, true from `ANTHROPIC_API_KEY` env, false when neither.
- `rank_products`: no key -> None; no candidates -> None; valid tool_use -> parsed dict; API error -> None (and a debug log); response without a tool_use block -> None.
- `synthesize_profile`: no key -> draft returned unchanged; valid tool_use -> merged profile with `source="heuristic+ai"`; API error -> draft returned with an `(AI refinement skipped: ...)` note.
- `resolve()` AI branch: `use_ai=False` -> heuristic; alias hit -> AI skipped; key absent -> heuristic; valid AI sku -> `method="ai"`; hallucinated/empty/sold-out sku -> heuristic fallback.
- New confidence blend: an inflated AI confidence is clamped to `min(ai_conf, heuristic_conf)`; an AI pick outside the heuristic top-N is forced to `needs_review`.
- `calibrated_confidence(top, runner_up)` direct unit test (shared by matcher + planner after the DRY extraction).

## Edge cases
- Empty candidate list into `resolve`/`rank_products`.
- Model returns an empty `favored_proteins` list — must not silently wipe the heuristic draft's proteins.
- `_first_tool_input` on a response whose content has only text blocks.

## Critical paths (must work end to end)
- `fd_match` with key set: live search -> heuristic shortlist -> AI re-rank -> blended confidence -> result (mock the AI call in tests).
- `fd_profile` with key set: signals -> heuristic draft -> AI refine -> saved profile.json.
- Both paths with key ABSENT must behave exactly as before the key existed (pure heuristic).

## Deferred (not in this plan)
- Prompt-quality eval against the real API (see TODOS.md). Unit tests cover plumbing, not pick quality; pick quality is currently gated by the human-review surface.
